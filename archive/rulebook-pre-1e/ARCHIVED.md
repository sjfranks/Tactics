# Archived: the pre-1e rulebook

`RULEBOOK.md` described the rules Emberwatch Tactics ran before it moved onto the **Rogue Tactics 1e** rule books (3d6 attack rolls, skills, per-deed experience, campfires that heal 40%). The game now follows the books in [`docs/rules/`](../../docs/rules/); [`docs/rules/ALIGNMENT.md`](../../docs/rules/ALIGNMENT.md) lists where the code still differs from them.
