# Rogue Tactics 1e — Rule Books

These are the rule books the game follows. They replace the older Emberwatch rules, now in [`archive/rulebook-pre-1e/`](../../archive/rulebook-pre-1e/). [`ALIGNMENT.md`](ALIGNMENT.md) lists where the code still differs.

| Book | What is in it |
|---|---|
| [Core Rules](core-rules.md) | How to play: dice and checks, health, combat, the run, making a hero, equipment, a summary of powers |
| [Heroes](heroes.md) | The classes, their powers, general powers, weapons and smith upgrades, and how the classes combo |
| [Bestiary](bestiary.md) | Foe types and roles, Malice and threats, the three regions' foes and bosses, encounter building, missions |
| [Design Notes](design-notes.md) | Changelog, why the rules work as they do, open questions |

The plan for bringing the code in line with these books is in [ALIGNMENT.md](ALIGNMENT.md).

The books are kept in Obsidian; the copies here are version **0.25** ("Chips × Mult"). Obsidian callouts (`> [!note]`) show as quotes on GitHub.
